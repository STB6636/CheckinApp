1. ระบบสุ่มระยะ GPS ขาออกงาน (วนค้นหาพื้นที่ใกล้เคียงจนกว่าจะได้ค่า)

เมื่อระบบสุ่มพิกัดขาออกงานตามระยะรัศมีที่กำหนดในตั้งค่า (เช่น 20 เมตร):

  • จะดำเนินการค้นหาชื่อสถานที่ใกล้เคียงแบบ Resilient Resolution Loop (สูงสุด 3-4 รอบ)
  • หากพิกัดสุ่มจุดแรกไม่พบชื่อสถานที่ หรือคืนค่าไม่ระบุสถานที่ ระบบจะขยับมุมองศาภายในรัศมีที่กำหนดแล้วสแกนซ้ำจนกว่าจะได้ชื่อสถานที่/ซอยที่ถูกต้อง ก่อนบันทึกลงฐานข้อมูล
  • มีผลครอบคลุมทั้ง:
    1. การลงเวลารูปแบบพิเศษ (บันทึกครั้งเดียว)
    2. การลงเวลาปฏิบัติงานนอกเวลา (Overtime)
    3. การส่งคำขอลงเวลากรณีพิเศษ (Special Request)
2. ระบบเลือกพิกัดในคำขอลงเวลากรณีพิเศษ (สไตล์แชร์ Location ใน LINE)

ในหน้าต่างโมดอล แบบคำขอลงเวลากรณีพิเศษ เพิ่มส่วนการเลือกพิกัดสถานที่ปฏิบัติราชการ:

ตัวเลือก 1: ใช้พิกัด GPS ปัจจุบัน ดึงพิกัดจริงจากอุปกรณ์ปัจจุบัน พร้อมแสดงชื่อสถานที่ที่ตรวจพบ
ตัวเลือก 2: ปักหมุด / ค้นหาสถานที่เอง ค้นหาด้วยชื่อสถานที่ หรือพิมพ์พิกัดละติจูด ลองจิจูด หรือคลิก/ลากหมุดบนแผนที่ได้เองทันที
// คุณสมบัติของแผนที่ปักหมุด (Interactive Leaflet Map):
✓ ลากหมุด (Drag Pin) ไปวางตำแหน่งที่ต้องการได้อิสระ
✓ แตะหรือคลิกบนแผนที่ (Click to Move) เพื่อย้ายหมุดมายังตำแหน่งนั้นทันที
✓ ค้นหาชื่อสถานที่ในไทย (Search Nominatim) นำทางหมุดไปจุดหมายอัตโนมัติ
✓ ระบบดึงชื่อสถานที่ใกล้เคียงแบบ Real-time แสดงผลทันทีเมื่อหมุดหยุดเคลื่อนที่
✓ นำพิกัดนี้ไปใช้บันทึกเป็นเวลาเข้างาน และนำไปสุ่มระยะขาออกงานตามกฎที่ตั้งไว้
