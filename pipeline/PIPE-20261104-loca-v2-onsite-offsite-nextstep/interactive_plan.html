PIPE-20261104-loca-v2-onsite-offsite-nextstep แนวทาง A: Schema "staging" ใน Supabase เดิม Branch: Loca-V2

แผนพัฒนาระบบลงเวลา Branch Loca-V2 (แนวทาง A: แยก Schema ทดสอบใน Supabase เดิม)

ใช้ URL และ Key เดิม 100% แต่แยกโครงสร้างข้อมูลทดสอบไปไว้ที่ Schema staging เพื่อความปลอดภัยสูงสุด ข้อมูลทดสอบไม่ปนกับข้อมูลจริงของระบบบน Cloudflare Pages

แนวทาง A: แยก Schema "staging" บน Supabase เดิม (ไม่ต้องเปลี่ยน URL/Key)

ความปลอดภัยสูงสุด • ข้อมูลแยกขาดจากระบบจริง
1 สคริปต์ SQL โคลนตาราง (`sql/create_staging_schema.sql`)

สร้าง Schema staging พร้อมคัดลอกตาราง system_settings, personnel, user_accounts และ attendance_logs มาไว้ใน staging โดยก๊อปปี้ข้อมูลบุคลากรและบัญชีเดิมมาให้ครบ เพื่อให้ท่านสามารถล็อกอินเข้าทดสอบได้ทันที

2 ในโค้ด `Config.js` & `DatabaseService.js`

บน Branch Loca-V2 จะเพิ่มเพียงบรรทัดเดียว: static SUPABASE_SCHEMA = 'staging'; (โดยที่ URL และ Key ใช้ชุดเดิม)
ใน DatabaseService.js ส่ง db: { schema: 'staging' } ทำให้ทุกหน้าใน Loca-V2 ชี้ไปที่ฐานข้อมูลทดสอบอัตโนมัติ 100%

3 ตั้งค่าบน Supabase Dashboard 1 จุด

เข้าไปที่ Project Settings > API > PostgREST > Exposed Schemas แล้วเพิ่มคำว่า staging เข้าไปคู่กับ public (ทำครั้งเดียวใน 30 วินาที) เพื่อเปิดให้เว็บดึงข้อมูลจาก Schema ใหม่ได้

ลำดับ Next Step 2 ขั้นตอนแบบ Zero-Scroll (100dvh): [1. พิกัด+ช่วงเวลา] ➔ [2. ถ่ายรูป & บันทึก]

ขั้นตอนที่ 1 (หน้าแรก): พิกัดสถานที่ + ช่วงเวลานอกเวลา (ถ้ามี)
  • โหมดในสถานที่ (ค่าเริ่มต้น): คำนวณรัศมีเทียบกับทุกสถานที่ในแท็บ "สถานที่และรัศมี" หากอยู่ในรัศมีอนุญาตให้ไปต่อ หากอยู่นอกรัศมีล็อกปุ่มถัดไปและแจ้งเตือน "พิกัดตำแหน่งอยู่นอกสถานที่ทำงาน" (ไม่เสียเวลาเปิดกล้องเก้อ)
  • โหมดนอกสถานที่: เลือกรูปแบบการปฏิบัติงาน (ช่องกรอก "อื่นๆ" เปิดเป็นป๊อปอัปเพื่อไม่ให้ดันความสูงหน้าจอ) + เลือกพิกัด GPS 2 ตัวเลือก (พิกัดปัจจุบัน หรือ ค้นหาสถานที่เอง)
  • ช่วงเวลานอกเวลา: แสดงกล่องเลือกช่วงเวลากระชับด้านล่างการ์ดพิกัด (เฉพาะเมื่อเป็นนอกเวลา)
  • ปุ่มขอบล่างจอ: แสดง "ปุ่มถัดไป" (สีเหลือง)
ขั้นตอนที่ 2 (หน้าสุดท้าย): ถ่ายรูปยืนยันตัวตน & บันทึกเวลา
  • แสดงแถบสรุปพิกัด/ช่วงเวลาที่เลือกไว้ (กดย้อนกลับไปแก้ไขได้)
  • แสดงกรอบกล้องถ่ายภาพแนวตั้ง 3:4 เพื่อยืนยันตัวตน
  • ปุ่มขอบล่างจอ: แสดง "บันทึกลงเวลาปฏิบัติงาน" (สีเขียว)
  • เมื่อกดยืนยัน จะแสดงลำดับ Popup: สรุปข้อมูล ➔ "ระบบกำลังบันทึกข้อมูล" ➔ "ลงเวลาปฏิบัติงานเรียบร้อยแล้ว"

หน้าจัดการข้อมูลบุคลากร (กรองข้อมูลตามโครงสร้างองค์กร 3 ระดับ)

เพิ่มแผง "กรองข้อมูลตามโครงสร้างองค์กร (ขอบเขต สำนักงาน/กอง)" แบบ 3 ระดับ (1. สำนักงาน/กอง > 2. ส่วน/ฝ่าย > 3. กลุ่มงาน) เหมือนหน้ารายงานการลงเวลา สำหรับบัญชี SuperAdmin และ Admin เฉพาะขอบเขตการมองเห็น สำนักงาน/กอง
