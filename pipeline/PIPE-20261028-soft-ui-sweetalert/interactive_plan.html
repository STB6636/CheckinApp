แผนปรับปรุง: ปรับธีมการแจ้งเตือน "ดำเนินการสำเร็จ" เป็น Soft UI Dashboard

Pipeline ID: PIPE-20261028-soft-ui-sweetalert | Reference: Creative Tim Soft UI Dashboard

Streamlined 2-SubAgent Mode
วิเคราะห์สาเหตุ (Current State vs Target)

ในปัจจุบัน UIHelpers.confirm() ได้รับการตกแต่งปุ่มและกล่องข้อความแบบ Soft UI Dashboard แล้ว แต่ฟังก์ชัน UIHelpers.alert() ยังคงเป็นการเรียก window.Swal.fire() แบบพื้นฐาน (Default SweetAlert2) โดยไม่มี customClass หรือ buttonsStyling: false ทำให้เมื่อแจ้งเตือน "ดำเนินการสำเร็จ" (เช่น เมื่อกดอนุมัติเวลา, แก้ไขข้อมูล, บันทึกการตั้งค่า) จะแสดงผลเป็นกล่องเหลี่ยมพร้อมปุ่มสีเขียวเรียบแบบดั้งเดิม

แนวทางแก้ไขระดับ Surgical (เฉพาะจุด)
// assets/js/core/UIHelpers.js -> UIHelpers.alert(title, text = '', icon = 'success')
- return window.Swal.fire({ title, text, icon, confirmButtonText: 'ตกลง', confirmButtonColor: ... });
+ return window.Swal.fire({
+     title, text, icon, confirmButtonText: 'ตกลง',
+     buttonsStyling: false,
+     customClass: {
+         popup: 'rounded-3xl p-6 sm:p-7 shadow-2xl border border-emerald-500/20 bg-white/95 dark:bg-slate-900/95 backdrop-blur-md max-w-sm sm:max-w-md',
+         title: 'text-base sm:text-lg font-bold text-slate-800 dark:text-white pt-2',
+         htmlContainer: 'text-xs sm:text-sm text-slate-600 dark:text-slate-300 m-0 pt-1.5 leading-relaxed',
+         confirmButton: 'inline-block px-7 py-2.5 mb-0 font-bold text-center uppercase align-middle transition-all bg-transparent border-0 rounded-xl cursor-pointer shadow-soft-md bg-x-25 bg-150 leading-pro text-xs ease-soft-in tracking-tight-soft bg-gradient-to-tl from-[#00744B] to-emerald-500 hover:scale-102 hover:shadow-soft-xs active:opacity-85 text-white',
+         actions: 'flex justify-center mt-4'
+     }
+ });

รองรับทั้งสถานะ success, warning, error, info พร้อมไล่สี Gradient สวยงามตามแบบฉบับ Creative Tim Soft UI Dashboard และรองรับ Dark Mode 100%
