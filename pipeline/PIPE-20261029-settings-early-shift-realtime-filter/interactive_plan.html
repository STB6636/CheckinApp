แผนงาน: ให้เริ่มเลือกทำงานก่อนเวลาเริ่มงานได้ (Real-time Filter)

Git Branch: TimeCheckin • Target Mode: PLAN -> 2 SubAgents (Lean Execution)

รอยืนยันแผนงาน

1. คำสั่ง SQL ปรับปรุงฐานข้อมูล (Supabase SQL Editor)

เพิ่มคอลัมน์ early_shift_window_minutes ในตาราง system_settings สำหรับเก็บจำนวนนาทีก่อนเวลาเริ่มงาน (Default: 30 นาที)
(หมายเหตุ: อ็อบเจกต์ช่วงเวลาใน work_shifts เป็น JSONB อยู่แล้ว จึงเพิ่มฟิลด์ allow_early_checkin: boolean ได้โดยตรง) 

-- เพิ่มคอลัมน์ early_shift_window_minutes ในตาราง system_settings (ค่าเริ่มต้น 30 นาที)
ALTER TABLE public.system_settings 
ADD COLUMN IF NOT EXISTS early_shift_window_minutes INTEGER DEFAULT 30;

-- อัปเดตแถวที่มีอยู่ให้มีค่าเริ่มต้น 30 นาที
UPDATE public.system_settings 
SET early_shift_window_minutes = 30 
WHERE early_shift_window_minutes IS NULL;

2. ตรรกะการคำนวณช่วงเวลา (Business Logic Flow)

การตั้งค่าระบบ & กะทำงาน
  • แท็บ 1: เพิ่มช่องกรอก เวลาเริ่มทำงานก่อนเวลาของช่วงเวลา (นาที) เช่น 30 นาที
  • แท็บ 3 (โมดอลกะ): เพิ่มเงื่อนไขติ๊กถูก ให้เริ่มเลือก ทำงานก่อนเวลาเริ่มงานได้
  • มีผลเฉพาะช่วงเวลาที่มีการติ๊กถูกเงื่อนไขนี้เท่านั้น
การทำงานจริงที่หน้าลงเวลา (Checkin)
  • เปิดฟังก์ชัน Real-time Filter = ON
  • ช่วงเวลา A เริ่มงาน 17:00 น. | ตั้งค่าล่วงหน้า 30 นาที
  • เวลาเริ่มปรากฏใน Dropdown: [17:00 - 30 นาที] = 16:30 น.
  • รองรับกะข้ามวัน (Overnight) และช่วงเวลาที่คาบเกี่ยวเที่ยงคืนอย่างถูกต้อง

3. รายละเอียดการแก้ไขแบบ Surgical (แก้ไขเฉพาะส่วนที่เกี่ยวข้อง)

1. assets/js/core/Config.js Default Values

เพิ่ม early_shift_window_minutes: 30 ใน DEFAULT_SETTINGS และ allow_early_checkin: false ใน work_shifts มาตรฐาน

2. assets/js/models/SettingsModel.js Data & Resilience

รองรับการโหลด/บันทึก early_shift_window_minutes และ allow_early_checkin พร้อมระบบ Fallback Retry และ localStorage กรณีคอลัมน์ยังไม่ถูกสร้างใน Supabase

3. settings.html UI Tab 1

เพิ่มช่องกรอกจำนวนนาที setEarlyShiftWindowMinutes ใต้สวิตช์ Real-time Filter ในแท็บ 1 สไตล์เดียวกับรัศมี GPS

4. assets/js/controllers/SettingsController.js Settings Controller

ผูกค่าช่องกรอกนาทีในแท็บ 1, เพิ่ม Checkbox ทำงานก่อนเวลาเริ่มงานได้ ในโมดอลกะทำงาน, บันทึกและแสดงผลตารางเดิมอย่างสมบูรณ์แบบ

5. assets/js/controllers/CheckinController.js Checkin Controller

ปรับแต่ง #isShiftActiveAtCurrentTime ให้คำนวณเวลาเริ่มต้นของกะด้วย [startMin - earlyWindow] เมื่อกะนั้นเปิดใช้เงื่อนไข

4. ข้อควรระวังและมาตรการป้องกันผลกระทบ (Safeguards)

  • ตารางกะและ Layout ไม่เปลี่ยนรูป: คอลัมน์ทุกคอลัมน์ของตารางช่วงเวลาในแท็บ 3 ยังคงแสดงผลและจัดเรียงได้ตามปกติ
  • SubAgent Lean Structure: ใช้ SubAgent 1 ตัวในการแก้ไขโค้ด (Flash 3.8 High) และ SubAgent 1 ตัวในการตรวจทานเทียบกับ Branch main (Flash 3.8 High) เพื่อประหยัดโทเคนสูงสุดตามคำสั่ง
  • การคำนวณเวลาข้ามวัน: ตรวจสอบกรณีที่คำนวณเวลาติดลบหรือข้ามคืน ให้เข้าเงื่อนไขอย่างถูกต้องแม่นยำ
