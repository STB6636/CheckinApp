Before (พังบน Cloudflare Pages)

2. getRootBasePath('/loading') → /loading/
3. location.replace('loading.html?entry=session')
4. ผลลัพธ์: /loading/loading.html?entry=session (วนลูปหน้าจอเขียว)

2. GitHub Pages: /CheckinApp/loading → /CheckinApp/
3. UIHelpers.resolveAppUrl('checkin.html') → /checkin.html
