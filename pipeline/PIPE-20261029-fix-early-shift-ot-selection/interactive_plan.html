แผนงานแก้ไข: ปลดล็อกตัวเลือกกะนอกเวลาช่วงเริ่มงานล่วงหน้า (Early OT Shift)

Git Branch: TimeCheckin • Target: CheckinController.js (Surgical Fix)

รอยืนยันแผนงาน

1. สาเหตุของปัญหา (Root Cause Analysis)

สถานการณ์: ตั้งค่าเวลาเริ่มทำงานก่อนเวลา 60 นาที, กะเริ่ม 17:00 น. (ช่วง Active คือ 16:00 - 01:00 น.) และเปิดใช้ "ปิดการลงเวลาในช่วงเวลาปกติ (08:30 - 16:30 น.)"

จุดที่บล็อกการทำงาน (ณ เวลา 16:02 น.):

  1. เวลา 16:02 น. ยังอยู่ในช่วงเวลาราชการปกติ (< 16:30 น.) ระบบตรวจพบว่า disable_normal_hours_checkin เปิดอยู่ จึงสั่งซ่อน Dropdown ตัวเลือกกะและ Disable ปุ่มบันทึกเวลาหน้าหลักทันที
  2. ตัวแปร mustUseOvertimeWindow ถูกผูกไว้เฉพาะหลัง 16:30 น. หรือก่อน 06:00 น. เท่านั้น ทำให้เวลา 16:02 น. ไม่ถูกจัดเป็นหน้าต่างเวลา OT
  3. เมื่อกดบันทึกเวลา ฟังก์ชัน #handleMainCheckin มีการตรวจดักช่วงเวลา 08:30 - 16:30 น. โดยไม่ได้ยกเว้นกรณีที่ผู้ใช้เลือกลงเวลาเป็นกะนอกเวลา (OT)

2. แนวทางการแก้ไขอย่างแม่นยำ (Surgical Fix)

1. ตรวจจับกะนอกเวลาที่ Active ในขณะนั้น (hasActiveOtShifts)

ตรวจสอบว่ามีกะนอกเวลา (OT) ที่อนุญาตให้เริ่มเข้างานล่วงหน้าและ Active อยู่ในเวลาปัจจุบันหรือไม่ หากมี ให้เปิดให้แสดง Dropdown ตัวเลือกกะทันที

2. ปรับการทำงานของ disable_normal_hours_checkin

กรณีเปิดปิดลงเวลาปกติ: ให้ปิดเฉพาะการลงเวลาปกติ (ตัดตัวเลือกเวลาราชการปกติออก) แต่เปิดแสดง Dropdown กะนอกเวลา ให้เจ้าหน้าที่สามารถเลือกกะ 17:00 น. และกดบันทึกลงเวลาได้ตั้งแต่ 16:00 น.

3. ยกเว้นการบล็อกใน #handleMainCheckin สำหรับกะนอกเวลา

หากกะที่เลือกเป็น is_overtime ให้บันทึกเวลาเป็นปฏิบัติงานนอกเวลาได้ทันที ไม่ถูกบล็อกโดยกฎ 08:30 - 16:30 น.

3. คำสั่ง SQL ฐานข้อมูล

ปัญหาในเคสนี้เกิดจากตรรกะเงื่อนไขการควบคุมการแสดงผลใน CheckinController.js บนฝั่ง Client-Side ฐานข้อมูลมีฟิลด์ early_shift_window_minutes และ JSONB work_shifts พร้อมสมบูรณ์แล้ว จึงไม่กระทบโครงสร้างฐานข้อมูลเพิ่มเติม (แต่ได้เตรียมคำสั่ง SQL เดิมไว้ให้ตรวจสอบความสมบูรณ์เรียบร้อย)
