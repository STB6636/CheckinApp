Enhancement Architecture Plan

ระบบตัวกรองโครงสร้างองค์กรลำดับชั้น และมุมมองจัดกลุ่ม 2 ระดับ (หน้าจัดการบัญชีผู้ใช้งาน)

PIPE-20261029-users-hierarchical-filter-and-group-view • Proposed Branch: User-Fillter

วัตถุประสงค์และข้อกำหนดสำคัญ (User Mandates):
1. อ้างอิงตั้งค่าระบบ

ดึงข้อมูลผังองค์กรจาก SettingsModel.getUniqueBureaus(), getUniqueDivisions(), getUniqueGroups()

2. เลือกไล่ลำดับชั้นเสมอ

เริ่มต้น [ส่วน/ฝ่าย] และ [กลุ่มงาน] จะถูก Disabled และปลดล็อกเมื่อเลือกระดับบนตามลำดับ

3. มุมมองจัดกลุ่ม 2 รูปแบบ

• มุมมองที่ 1: กอง > ฝ่าย
• มุมมองที่ 2: กอง > ฝ่าย > กลุ่มงาน (เหมือนหน้าบุคลากร)

โครงสร้าง UI และการทำงานใหม่ (UI Blueprint):

A แถวควบคุมการค้นหา (Row 1): Search + Role Filter + มุมมองจัดกลุ่ม (Group By)

เพิ่ม Dropdown #selectUserGroupBy มี 2 ตัวเลือก: "มุมมองที่ 1: สำนักงาน/กอง > ส่วน/ฝ่าย" และ "มุมมองที่ 2: สำนักงาน/กอง > ส่วน/ฝ่าย > กลุ่มงาน"

B Dock ตัวกรองโครงสร้างองค์กรลำดับชั้น (Row 1.5): เฉพาะ SuperAdmin และ Admin กอง

เพิ่ม #hierarchicalUserOrgFilterDock พร้อม 3 Dropdowns (กอง, ฝ่าย, กลุ่มงาน) ปิด/เปิดตามลำดับชั้น และซ่อนอัตโนมัติสำหรับ Admin ระดับฝ่าย

C ตารางแสดงผลแบบจัดกลุ่มหัวเรื่อง (Grouped Table Rendering)

ใช้ PersonnelModel.groupPersonnel() จัดกลุ่มบัญชีผู้ใช้ตามสังกัดของบุคลากรที่ผูกอยู่ แสดงแถวหัวข้อ กอง > ฝ่าย และ กลุ่มงาน อย่างสวยงาม

ข้อควรระวังสำคัญ (Safeguards):
  • ตารางหลัก & คอลัมน์: แสดงผล 6 คอลัมน์ครบถ้วน (ลำดับ, Username, ชื่อ-นามสกุล, Role, ขอบเขตการมองเห็น, จัดการ)
  • ตารางที่ 2 (อนุมัติเปลี่ยนรหัสผ่าน): ยังคงแสดงผลและทำงานได้ปกติ 100% ไม่ถูกรบกวน
  • ปุ่มคำสั่ง (Actions): ปุ่มแก้ไข, ลบ, รีเซ็ตรหัสผ่าน, นำเข้า Excel และส่งออก Excel ทำงานได้สมบูรณ์
  • RBAC Guard: Admin ฝ่ายจะไม่สามารถเห็น Dock กรองนี้
