PIPE-20261027-shift-select-empty-and-soft-ui-confirm-alert

แผน Dropdown ค่าว่าง และใช้ SweetAlerts Soft UI ทั้งกล่องเตือนและกล่องยืนยัน

เป้าหมาย: บังคับเลือกช่วงเวลาด้วยตนเอง หากลืมเลือกจะแจ้งเตือนด้วย Soft UI SweetAlert พร้อมเลื่อนจอ และแสดงกล่องยืนยัน Soft UI ก่อนบันทึกจริง

Streamlined: SubAgent 2 ตัว (Flash Model)
1. Dropdown ค่าว่างเปล่า

เริ่มต้นด้วย <option value="">-- กรุณาเลือกช่วงเวลาปฏิบัติงาน --</option> ไม่เลือกอัตโนมัติ ให้ผู้ใช้เลือกช่วงเวลาด้วยตนเอง

2. เตือนด้วย Soft UI & เลื่อนจอ

หากลืมเลือกแล้วกดบันทึก จะแจ้งเตือนด้วย SweetAlerts Soft UI พร้อม scrollIntoView เลื่อนจอไปชี้เป้าที่ Dropdown ทันที

3. ยืนยันด้วย Soft UI

แสดงกล่องยืนยันสไตล์ Creative Tim Soft UI ระบุช่วงเวลาที่เลือกชัดเจน เมื่อผู้ใช้กด "ยืนยันบันทึกเวลา" จึงจะส่งข้อมูลเข้าระบบ

กล่องที่ 1: แจ้งเตือนเมื่อลืมเลือกช่วงเวลา (Soft UI)

กรุณาเลือกช่วงเวลาปฏิบัติงาน

ระบบตรวจพบว่าท่านยังไม่ได้ระบุช่วงเวลาทำงาน

กรุณาคลิกเลือกช่วงเวลาจากรายการก่อนทำการบันทึกลงเวลา
กล่องที่ 2: ยืนยันการบันทึกเวลา (Soft UI)

ยืนยันการบันทึกลงเวลา

ประเภท: บันทึกลงเวลาเข้าปฏิบัติงาน
ช่วงเวลา: เวลาราชการปกติ (08:30 - 16:30)

ข้อควรระวัง: ป้องกัน Scroll Bar บน PC

เนื่องจาก SweetAlert ทั้ง 2 ตัวทำงานเป็น Modal Popup แบบ Overlay ลอยอยู่เหนือหน้าจอ และไม่มีการแก้ไขความสูงของ Layout บนหน้าเว็บหลัก จึงไม่มีผลกระทบต่อความสูงโดยรวมบน PC และไม่ทำให้เกิด Scroll Bar แน่นอน 100%
