Pipeline: PIPE-20261028-special-modal-place-autocomplete | CheckinApp UX/UI

รายละเอียดองค์ประกอบของรายการตัวเลือก (Google Maps Pattern Breakdown)

เมื่อผู้ใช้พิมพ์คำค้นหาในช่องค้นหา ระบบจะประมวลผลข้อมูลสถานที่จาก Nominatim + พิกัดปัจจุบันของผู้ใช้ และจัดโครงสร้างการแสดงผลแต่ละรายการให้เหมือนกับ Google Maps ดังนี้:

1. ชื่อสถานที่หลัก (Primary Place Name)

แสดงชื่ออาคาร สถานที่สำคัญ หน่วยงานราชการ หรือจุดเด่นชัดเจน ตัวหนา ขนาด 12px (เช่น เสาชิงช้า หรือ ศาลาว่าการ กทม. 1)

2. ระยะทางโดยประมาณ (Proximity Distance)

คำนวณระยะห่างแบบ Haversine เทียบกับพิกัดปัจจุบันของผู้ใช้แบบ Real-time (เช่น • 350 ม. หรือ • 2.4 กม.)

3. ข้อมูลที่อยู่ย่อย (Secondary Subtitle)

แสดงชื่อถนน, แขวง/ตำบล, เขต/อำเภอ, จังหวัด เพื่อแยกแยะสถานที่ชื่อซ้ำกันได้อย่างแม่นยำ

4. ป้ายกำกับประเภทสถานที่ (Place Category Tag)

ระบุประเภท เช่น "สถานที่ราชการ", "วัด/ศาสนสถาน", "โรงพยาบาล", "สวนสาธารณะ", "อาคาร/สำนักงาน"

ลำดับกระบวนการทำงานเมื่อผู้ใช้ใช้งาน (Interaction Flow)

  1. การพิมพ์คำค้นหา (Debounce 350ms): เมื่อพิมพ์ข้อความ ระบบจะหน่วงเวลา 350ms แล้วดึงข้อมูลจาก OpenStreetMap Nominatim Search API สูงสุด 5 รายการ พร้อมคัดเลือกสถานที่เฉพาะในประเทศไทย (countrycodes=th)
  2. การคำนวณระยะทางแบบไดนามิก: คำนวณระยะห่างเชิงพิกัด (Haversine formula) จากพิกัดของอุปกรณ์ปัจจุบันของผู้ใช้ไปยังผลลัพธ์แต่ละแห่ง เพื่อแสดงผลระยะทาง (เช่น • 350 ม. หรือ • 2.4 กม.) เพิ่มความสะดวกในการตัดสินใจเลือกสถานที่
  3. การคลิกเลือกสถานที่:
    • ใส่ชื่อสถานที่ที่เลือกลงในช่องค้นหา
    • ปิดเมนูตัวเลือกแบบลอยทันที
    • สั่งให้แผนที่ Leaflet บินอย่างนุ่มนวล (spLeafletMap.flyTo([lat, lng], 16))
    • ย้ายหมุดปักสีฟ้า (spLeafletMarker.setLatLng([lat, lng])) ไปยังตำแหน่งนั้น
    • อัปเดตตัวเลขพิกัดใน #spCustomCoordsDisplay และชื่อสถานที่ใน #spCustomLocNameDisplay
  4. การคลิกปิดหรือยกเลิก: คลิกพื้นที่ภายนอก (Click Outside) หรือกดปุ่ม Escape จะปิดเมนูตัวเลือกอัตโนมัติ
