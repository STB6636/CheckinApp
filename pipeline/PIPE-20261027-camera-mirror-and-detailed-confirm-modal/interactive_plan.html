แก้ไขกล้องกลับด้าน (Mirror) & แยกกล่องยืนยัน Soft UI ตามเงื่อนไข

อัปเดตล่าสุด: ตรวจสอบการเปิด/ปิด GPS ในตั้งค่าระบบ (หากปิด GPS จะไม่แสดงสถานที่)

Branch: Test-UXUI

1. กล้องกลับด้าน (หันซ้ายในจอหันขวา) สามารถแก้ได้ไหม?

คำตอบ: สามารถแก้ไขได้ 100% ครับ

เราจะใส่ Mirror Effect ด้วย CSS transform: scaleX(-1) (ใน Tailwind คือ -scale-x-100) ให้กับวิดีโอกล้องสด และทำการกลับทิศแนวนอนบน Canvas ขณะบันทึกภาพถ่าย เพื่อให้ทั้งตอนเล็งพรีวิวและรูปที่ได้ เป็นมุมมองกระจกเงา (Mirror View) เสมือนส่องกระจกจริงทุกประการ

ปัจจุบัน: Observer View (กล้องเว็บแคมปกติ)

ผู้ใช้หันซ้าย ➔ ในจอภาพหันไปทางขวา (ฝืนสายตา)

แก้ไขใหม่: Mirror View (เหมือนส่องกระจก)

ผู้ใช้หันซ้าย ➔ ในจอภาพหันไปทางซ้ายตาม (เป็นธรรมชาติ 100%)

2. การแยกแสดงข้อมูลในกล่องยืนยัน SweetAlerts Soft UI

จำลองการตั้งค่าระบบ:
เงื่อนไขการแสดงผล:
  • รูปแบบปกติ: แสดง ช่วงเวลาบันทึก: "เวลาเข้างาน" หรือ "เวลาออกงาน" (ไม่แสดงเวลา)
  • รูปแบบพิเศษ: แสดง ชื่อช่วงเวลา, เวลาเข้างาน, เวลาออกงาน
  • การควบคุม GPS: หากระบบตั้งค่า ปิดใช้งาน GPS จะ ไม่แสดงข้อ "สถานที่ ตาม GPS" ในกล่องยืนยันโดยอัตโนมัติ
ปกติ: ขาเข้างาน 3 ข้อ
  • 1. ช่วงเวลาบันทึก: เวลาเข้างาน
  • 2. เวลาขณะบันทึก: 08:24:15 น.
  • 3. สถานที่ ตาม GPS:
    • ชื่อสถานที่ใกล้เคียง
    • (พิกัด: 13.752312, 100.501234)
ปกติ: ขาออกงาน 3 ข้อ
  • 1. ช่วงเวลาบันทึก: เวลาออกงาน
  • 2. เวลาขณะบันทึก: 16:35:10 น.
  • 3. สถานที่ ตาม GPS:
    • ชื่อสถานที่ใกล้เคียง
    • (พิกัด: 13.752312, 100.501234)
รูปแบบพิเศษ (กะ/OT) 4 ข้อ
  • 1. ชื่อช่วงเวลา: กะบ่าย / OT
  • 2. เวลาเข้างาน: 16:30 น.
  • 3. เวลาออกงาน: 20:30 น.
  • 4. สถานที่ ตาม GPS:
    • ชื่อสถานที่ใกล้เคียง
    • (พิกัด: 13.769123, 100.551842)
