ปรับปรุงกล่องยืนยันออกจากระบบ สไตล์ Soft UI Dashboard (Creative Tim)

ตามมาตรฐาน Creative Tim Tailwind SweetAlerts Soft UI

Branch: Test-UXUI

1. เปรียบเทียบรูปแบบกล่องแจ้งเตือนออกจากระบบ

รูปแบบเดิม (Default SweetAlert2)
  • ใช้สีพื้นฐานแบบ Inline Color (#E11D48 / #64748B)
  • ปุ่มทรงเหลี่ยมมนเล็ก ไม่มีเงาหรือมิติความนุ่มนวล
  • ไม่มีการ์ดสรุปข้อความ ไม่มีไอคอนกำกับในปุ่มกด
รูปแบบใหม่ (Soft UI Dashboard)
  • ขอบมนระดับพรีเมียม rounded-2xl พร้อม Backdrop Blur
  • ปุ่มยืนยัน Soft UI Gradient Rose-Red (from-rose-600 to-red-500)
  • ปุ่มยกเลิกสี Soft Slate นุ่มนวลตา พร้อมเอฟเฟกต์ hover:scale-102
  • การ์ดข้อความแจ้งเตือนสีนุ่มนวล พร้อมไอคอนออกจากระบบ

2. จุดที่ปรับใช้ในระบบทั้งแอปพลิเคชัน (3 จุดสำคัญ)

หน้าระบบลงเวลาปฏิบัติราชการ (checkin.html)

ครอบคลุมทั้งปุ่ม "ออกจากระบบ" บนแถบเมนูบนหน้าจอคอมพิวเตอร์ และปุ่มออกจากระบบในเมนูด้านข้าง (Slide Drawer) บนมือถือ

หน้าผู้ดูแลระบบ (Admin Layout Shell)

ครอบคลุมปุ่ม "ออกจากระบบ" ด้านล่างของ Sidebar เมนูผู้ดูแลระบบ (ทุกหน้า: Dashboard, Approvals, Reports, Personnel, Users, Settings)
