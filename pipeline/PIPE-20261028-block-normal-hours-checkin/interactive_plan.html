แผนปรับปรุง: เปิด/ปิดการลงเวลาในช่วงเวลาปกติ (08:30 - 16:30 น.)

Pipeline ID: PIPE-20261028-block-normal-hours-checkin | Branch: feature-lock-normal-hours

Streamlined 2-SubAgent Mode
ความต้องการระบบที่ปรับแก้ตามข้อเสนอแนะ
  • 1. ตั้งค่าระบบ (Settings): มีสวิตช์ disable_normal_hours_checkin ในหน้า settings.html
  • 2. บล็อกเฉพาะปุ่มบันทึกเวลาหน้าหลักในช่วงเวลาปกติ (08:30 - 16:30 น.): เมื่ออยู่ในช่วงเวลาราชการปกติ (ตามค่า standard_check_in ถึง standard_check_out ในระบบ):
    • ปุ่มบันทึกเวลาหน้าหลัก #btnSubmitCheckinMain จะถูกปิดกั้น (Disabled) ทั้งในโหมดปกติและโหมดพิเศษ (ครั้งเดียว)
    • แสดงข้อความแจ้งเตือนสีส้มชัดเจน: "ระบบปิดรับการลงเวลาในช่วงเวลาราชการปกติ (08:30 - 16:30 น.)"
  • 3. หน้าต่างขอลงเวลากรณีพิเศษ (Special Check-in Modal):
    • ยื่นได้ตลอดเวลา ยังสามารถยื่นคำขอลงเวลากรณีพิเศษได้ตามปกติทุกช่วงเวลา 24 ชม. ไม่มีการบล็อกการส่งคำขอ
    • ซ่อนเวลาราชการปกติ ตัวเลือก "เวลาราชการปกติ" ใน Dropdown #spShiftSelect จะถูกซ่อนออกทั้งหมด เพื่อให้ผู้ใช้ยื่นขอได้เฉพาะการปฏิบัติงานนอกเวลา (Overtime) หรือกะพิเศษเท่านั้น
คำสั่ง SQL สำหรับ Supabase
-- เพิ่มคอลัมน์เปิด/ปิดการลงเวลาในช่วงเวลาราชการปกติ
ALTER TABLE system_settings
ADD COLUMN IF NOT EXISTS disable_normal_hours_checkin BOOLEAN DEFAULT FALSE;
ขอบเขตการแก้ไขไฟล์ (Surgical Scope)
  1. assets/js/core/Config.js: เพิ่ม disable_normal_hours_checkin: false ใน DEFAULT_SETTINGS
  2. settings.html: เพิ่ม Switch UI #toggleDisableNormalHoursCheckin
  3. assets/js/controllers/SettingsController.js: จัดการ Event โหลดและบันทึกค่า Switch
  4. assets/js/models/SettingsModel.js: บันทึกและดึงค่าจาก DB พร้อม Fallback ใน localStorage
  5. assets/js/controllers/CheckinController.js:
    • ปิดปุ่มบันทึกเวลาหน้าหลัก #btnSubmitCheckinMain เมื่ออยู่ในช่วง 08:30 - 16:30 น. (ทั้งรูปแบบปกติและพิเศษครั้งเดียว)
    • กรองตัวเลือก #spShiftSelect ในโมดอลกรณีพิเศษ ซ่อนรายการ "เวลาราชการปกติ" ออก แต่ยังคงอนุญาตให้ยื่นคำขอได้ตามปกติ 24 ชม.
