Bug Fix & Recovery Plan

แก้ไขข้อผิดพลาดระบบ Filter โครงสร้างองค์กรและกู้คืนการแสดงผลข้อมูล

PIPE-20261029-fix-reports-hierarchical-filter-crash • Branch: Report-Fillter

สาเหตุที่แท้จริง (Root Cause):

ใน ReportsController.js มีการเรียกใช้งาน UIHelpers.escapeHtml() ในเมธอด #populateHierarchicalOrgFilter() และใน catch (err) แต่ในคลาส UIHelpers.js ยังไม่มีฟังก์ชัน escapeHtml()

ทำให้เกิดข้อผิดพลาด TypeError: UIHelpers.escapeHtml is not a function ส่งผลให้กระบวนการโหลดข้อมูลหยุดชะงัก ตัวเลือกใน Dropdown จึงไม่ถูกสร้าง และการคำนวณ TAG กับการเรนเดอร์ตารางไม่ถูกประมวลผลต่อ

ขั้นตอนการดำเนินงาน (Execution Steps):

1 Implementer SubAgent

เพิ่ม static escapeHtml(str) ใน assets/js/core/UIHelpers.js ให้รองรับการ sanitize อักขระ HTML ได้อย่างปลอดภัยและมีประสิทธิภาพ

2 Verify Safeguards

ทดสอบการทำงานของ #populateHierarchicalOrgFilter(), ตรวจสอบการนับยอด Tag Badges และทดสอบการเรนเดอร์ตารางแยกสถานะ

3 QA Auditor SubAgent

ตรวจสอบเปรียบเทียบ diff กับ main รัน Automated Assertions ยืนยันว่า Dropdown แสดงข้อมูลหน่วยงานจริงครบถ้วน

ข้อควรระวังสำคัญ (Safeguards):
  • แก้เฉพาะฟังก์ชันที่ขาดหาย ไม่แตะต้องตรรกะระบบอื่น
  • ข้อมูลหน่วยงานภาษาไทยต้องเรียงลำดับพจนานุกรมอย่างถูกต้อง
  • ตัวเลือกเริ่มต้นยังคงเป็น "แสดงทั้งหมด" (`all`)
  • ปุ่ม TAG สถานะ และแถวตารางต้องเรนเดอร์ข้อมูลจริงอย่างถูกต้อง 100%
