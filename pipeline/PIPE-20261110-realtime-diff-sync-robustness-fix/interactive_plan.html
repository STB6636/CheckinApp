🚨 การค้นพบต้นตอที่แท้จริงเพิ่มเติม (The Real Blockers Uncovered)

1. ReportsController: Bug `status_key` vs `status_category`

ใน ReportsController.js เช็ค if (prev.status_key !== fr.status_key) แต่ใน AttendanceModel.#formatReportRow() ส่งฟิลด์ชื่อ status_category (ไม่มี status_key) ทำให้เปรียบเทียบ undefined !== undefined ซึ่งเป็น false เสมอ 100%! ตารางรายงานจึงไม่เคยย้ายแถวข้ามตารางสถานะเลย!

2. ReportsController: Key Mismatch ใน `oldMap`

ก่อนลงเวลา แถวมี row_uid = "${person.id}_${workDate}_empty" แต่หลังลงเวลา กลายเป็น UUID ทำให้ oldMap.get(uuid) หาแถวเดิมไม่เจอ (ทั้งขา INSERT และ DELETE) ไม่เกิดการจับคู่เปรียบเทียบ

3. DashboardController: รายการ 5 อันดับล่าสุดเรียงตามชื่อ ฮ-ก

freshCheckedIn นำ Array ที่เรียงตามชื่อบุคลากร ก-ฮ มาทำ .reverse() ทำให้กลายเป็นการเรียง ฮ-ก! คนที่ลงเวลาใหม่แต่ชื่อไม่อยู่ท้ายพยัญชนะไทย จึงหลุดจาก 5 อันดับแรกและไม่ปรากฏบนหน้าจอ!
