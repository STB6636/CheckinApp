## 2. Updated Domain Rule Specification (v3.0):
- **`rule_format_position_and_hide_non_level` (กฎการจัดรูปแบบตำแหน่งและการเว้นวรรคระดับ BMA):**
  1. **กรณีซ่อนระดับ (ไม่แสดงระดับ):**
     - ระดับเป็น `"ไม่มี"`, `"ระดับไม่มี"`, `"-"`, หรือค่าว่าง ➔ ไม่แสดงผลระดับ
       - เช่น `ตำแหน่ง: พนักงานเทศกิจ, ระดับ: ไม่มี` ➔ แสดงค่าเป็น `"พนักงานเทศกิจ"`
       - เช่น `ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: ไม่มี` ➔ แสดงค่าเป็น `"พนักงานขับรถยนต์"`
     - ประเภทตำแหน่งเป็น `"ประเภทผู้บริหาร"` (หรือมีคำว่า `"ผู้บริหาร"`) ➔ ไม่แสดงผลระดับ
       - เช่น `ประเภทตำแหน่ง: ประเภทผู้บริหาร, ตำแหน่ง: ผู้อำนวยการส่วน, ระดับ: อำนวยการระดับสูง` ➔ แสดงค่าเป็น `"ผู้อำนวยการส่วน"`
       - เช่น `ประเภทตำแหน่ง: ประเภทผู้บริหาร, ตำแหน่ง: หัวหน้ากลุ่มงาน, ระดับ: ชำนาญการพิเศษ` ➔ แสดงค่าเป็น `"หัวหน้ากลุ่มงาน"`
  2. **กรณีเว้นวรรค 1 ช่องระหว่าง [ตำแหน่ง] และ [ระดับ] (`${title} ${level}`):**
     - เมื่อประเภทตำแหน่งเป็น `"ลูกจ้างประจำ"` (หรือมีคำว่า `"ลูกจ้าง"`)
     - หรือเมื่อระดับเป็นกลุ่มลูกจ้าง เช่น `ส 1, ส 2, ส 3, ส 4, ส.1 - ส.4, บ 1, บ 2, บ 3, บ 4, บ.1 - บ.4`
     - หรือระดับขึ้นต้นด้วยตัวเลข เช่น `1, 2, 3, 4`
     - *ตัวอย่าง:* `ประเภทตำแหน่ง: ลูกจ้างประจำ, ตำแหน่ง: พนักงานเทศกิจ, ระดับ: ส 2` ➔ แสดงผลเป็น `"พนักงานเทศกิจ ส 2"`
     - *ตัวอย่าง:* `ประเภทตำแหน่ง: ลูกจ้างประจำ, ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: 2` ➔ แสดงผลเป็น `"พนักงานขับรถยนต์ 2"`
     - *ตัวอย่าง:* `ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: บ 1` ➔ แสดงผลเป็น `"พนักงานขับรถยนต์ บ 1"`
  3. **กรณีติดกัน ไม่เว้นวรรค (ข้าราชการสามัญปกติ `${title}${level}`):**
     - ข้าราชการสามัญที่มีระดับมาตรฐานราชการไทย (เช่น ปฏิบัติการ, ชำนาญการ, ชำนาญการพิเศษ, เชี่ยวชาญ, ทรงคุณวุฒิ, ปฏิบัติงาน, ชำนาญงาน, อาวุโส, ทักษะพิเศษ)
     - *ตัวอย่าง:* `ประเภทตำแหน่ง: ข้าราชการกรุงเทพมหานครสามัญ, ตำแหน่ง: นักจัดการงานทั่วไป, ระดับ: ปฏิบัติการ` ➔ แสดงผลเป็น `"นักจัดการงานทั่วไปปฏิบัติการ"`
     - *ตัวอย่าง:* `ประเภทตำแหน่ง: ข้าราชการกรุงเทพมหานครสามัญ, ตำแหน่ง: เจ้าพนักงานเทศกิจ, ระดับ: ชำนาญการ` ➔ แสดงผลเป็น `"เจ้าพนักงานเทศกิจชำนาญการ"`
