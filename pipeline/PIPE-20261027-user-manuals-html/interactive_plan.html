ผู้ดูแลระบบสูงสุด (SuperAdmin)

เนื้อหาแต่ละคู่มือ (คลิกแท็บ)

  1. การเข้าสู่ระบบ (โหมดลงเวลา) / จดจำชื่อผู้ใช้
  2. เปลี่ยนรหัสผ่าน และแจ้งลืมรหัสผ่านด้วยเลขบัตรประชาชน 13 หลัก
  3. ส่วนประกอบหน้าลงเวลา (PC และมือถือ)
  4. ถ่ายภาพยืนยันตัวตน (กล้อง Mirror) และอนุญาตกล้อง/GPS
  5. ลงเวลาเข้า–ออกงานรูปแบบปกติ (กล่องยืนยัน Soft UI)
  6. ลงเวลารูปแบบพิเศษ / กะ / นอกเวลา (เลือกช่วงเวลา Dropdown)
  7. ยื่นคำขอลงเวลาพิเศษ/ย้อนหลัง และยกเลิกคำขอที่รออนุมัติ
  8. ดูประวัติการลงเวลา และความหมายสถานะ (ตรงเวลา/สาย/กลับก่อน/รออนุมัติ)
  9. สลับธีมสว่าง/มืด และออกจากระบบ
  10. คำถามที่พบบ่อย (FAQ) และการแก้ปัญหาเบื้องต้น
  1. ระดับสิทธิ์ Admin กอง vs Admin ฝ่าย และขอบเขตข้อมูลที่มองเห็น
  2. เข้าสู่ระบบโหมดจัดการ และโครงสร้างเมนู (Sidebar / มือถือ)
  3. หน้าภาพรวม (Dashboard) และการ์ดสถิติประจำวัน
  4. อนุมัติ/ไม่อนุมัติคำขอลงเวลาพิเศษ (รายรายการ/แบบกลุ่ม)
  5. รายงานการลงเวลา: กรองป้ายสถานะ, ดูรายละเอียด/ภาพ/GPS, แก้ไขบันทึก
  6. พิมพ์รายงาน PDF และส่งออก Excel
  7. จัดการข้อมูลบุคลากร และนำเข้า Excel แบบหลายแผ่นงาน
  8. จัดการบัญชีผู้ใช้ & อนุมัติรีเซ็ตรหัสผ่าน (เฉพาะ Admin กอง)
  9. กระดิ่งแจ้งเตือน และการสลับไปหน้าลงเวลา
  10. FAQ สำหรับผู้ดูแล
  1. ภาพรวมสิทธิ์ SuperAdmin (เข้าถึงทุกเมนู ทุกสังกัด)
  2. ตั้งค่าระบบทั่วไป: ชื่อหน่วยงาน, โลโก้, สีอัตลักษณ์
  3. ตั้งค่าการลงเวลา: เวลามาตรฐาน, ผ่อนผัน, บันทึกครั้งเดียว, กรองกะตามเวลาจริง
  4. เปิด/ปิด กล้องถ่ายภาพ และ GPS / เชื่อม Google Drive
  5. จัดการกะเวลาทำงาน (ปกติ/นอกเวลา/ข้ามคืน/กำหนดเอง)
  6. โครงสร้างตำแหน่ง 3 ระดับ และสังกัด 4 ระดับ
  7. จัดการบัญชีผู้ใช้: กำหนดบทบาทและขอบเขต Admin
  8. อ้างอิงทุกเมนูของ Admin (ลิงก์ไปคู่มือ Admin)
  9. แนวปฏิบัติด้านความปลอดภัยและการสำรองข้อมูล

รูปแบบการออกแบบ

  • ธีม กทม. (เขียว #00744B) + Soft UI • สารบัญด้านข้าง (ยุบเป็นเมนูบนมือถือ)
  • กล่อง ขั้นตอน (Step), เคล็ดลับ, ข้อควรระวัง • ตารางสิทธิ์เปรียบเทียบ 3 ระดับ
  • ปุ่มพิมพ์/บันทึก PDF • สลับโหมดมืด • ไม่ต้องล็อกอินเพื่อเปิดอ่าน
