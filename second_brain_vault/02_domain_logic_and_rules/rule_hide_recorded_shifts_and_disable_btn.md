# Domain Rule: ซ่อนช่วงเวลาที่ลงเวลาแล้ว และปิดปุ่มบันทึกเมื่อไม่มีตัวเลือกช่วงเวลา

## 1. วัตถุประสงค์ (Purpose)
ป้องกันความซ้ำซ้อนในการลงเวลาปฏิบัติราชการในรอบวันเดียวกัน โดยตัดตัวเลือกกะที่เจ้าหน้าที่ได้ทำการบันทึกลงเวลาไปแล้วออกจาก Dropdown ทันที และปิดการทำงานของปุ่มบันทึกเวลาหน้าหลักหากไม่มีตัวเลือกช่วงเวลาที่สามารถบันทึกได้เหลืออยู่

## 2. กฎการทำงานทางธุรกิจ (Business Logic & Rules)

1. **การซ่อนกะที่ลงเวลาแล้ว (`#isShiftAlreadyRecordedToday`):**
   - เมื่อผู้ใช้บันทึกลงเวลากะ A (เช่น เวลาราชการปกติ หรือ กะนอกเวลา) สำเร็จในรอบวันปัจจุบัน
   - ในการรีเฟรชหรือประเมินช่วงเวลา ระบบจะตรวจสอบกับ `todayHistoryList` (ประวัติการลงเวลาของวันนี้)
   - กะที่ตรงกันทั้งชื่อรูปแบบเต็ม และเวลาเข้า-ออกงาน จะถูกตัดออกจาก `candidateShifts` ทันที และไม่ปรากฏใน Dropdown อีกในวันนั้น

2. **การซ่อนเวลาราชการปกติเมื่อเปิดฟังก์ชันปิดรับเวลาปกติ:**
   - เมื่อเปิดใช้ฟังก์ชัน `disable_normal_hours_checkin === true` ("ปิดการลงเวลาในช่วงเวลาปกติ (08:30 - 16:30 น.)")
   - ตัวเลือก "เวลาราชการปกติ (08:30 - 16:30)" จะถูกกรองออกจาก Dropdown ทันที ไม่ปรากฏให้เลือก

3. **การปิดปุ่มเมื่อไม่มีช่วงเวลาเหลือ (`disable checkin button`):**
   - หากช่วงเวลาทั้งหมดของวันนั้นถูกลงเวลาจนครบแล้ว หรือไม่มีกะที่ Active ในเวลาปัจจุบัน (`availableShiftsForCurrentWindow.length === 0`)
   - ระบบจะปิดการทำงานของปุ่มบันทึกเวลาหน้าหลัก (`btnSubmitMain.disabled = true;`)
   - ข้อความปุ่มเปลี่ยนเป็น: `"ไม่มีช่วงเวลาปฏิบัติงานให้บันทึก"`
   - Dropdown แสดงตัวเลือก: `"-- บันทึกลงเวลาครบทุกช่วงเวลาแล้ว / ไม่มีช่วงเวลาที่เปิดให้ลงเวลา --"`
   - กล่องแจ้งเตือน Notice Box ชี้แจง: `"ท่านได้บันทึกลงเวลาปฏิบัติงานในทุกช่วงเวลาที่เปิดให้ลงเวลาเรียบร้อยแล้ว หรือไม่มีช่วงเวลาปฏิบัติงานที่เปิดให้ลงเวลาในขณะนี้"`

4. **การคุ้มครองสถานะค้างลงเวลาออกงาน (`hasUnclosedRegular`):**
   - หากผู้ใช้ลงเวลาเข้างานปกติไว้และกำลังรอออกงาน (`hasUnclosedRegular = true`)
   - ปุ่ม *"บันทึกลงเวลาเลิกงาน"* จะต้องไม่ถูกปิดการทำงาน เพื่อให้เจ้าหน้าที่สามารถกดบันทึกเวลาเลิกงานได้ตามระเบียบ
