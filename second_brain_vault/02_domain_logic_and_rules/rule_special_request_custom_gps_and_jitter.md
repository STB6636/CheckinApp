# Domain Rule: ระบบสุ่มระยะ GPS ขาออกงานแบบค้นหาจนกว่าจะได้ค่า และการปักหมุดแผนที่ในคำขอลงเวลากรณีพิเศษ

- **Flow ID:** `FLOW_GPS_01`, `FLOW_SPECIAL_REQ_01`, `FLOW_CHECKIN_01`
- **Module:** `assets/js/models/AttendanceModel.js`, `assets/js/controllers/CheckinController.js`, `checkin.html`

## 1. ข้อกำหนดระบบสุ่มระยะ GPS ขาออกงาน (Jittered Checkout Location Loop)
1. **การวนซ้ำค้นหาสถานที่จนกว่าจะได้ค่า (`AttendanceModel.resolveJitteredCheckoutWithLocation`):**
   - เมื่อระบบต้องบันทึกเวลาขาออก (ไม่ว่าจะผ่านการลงเวลาครั้งเดียว, ทำงานนอกเวลา, หรือคำขอลงเวลากรณีพิเศษ) จะทำการสุ่มพิกัดรอบพิกัดตั้งต้น (Base Latitude/Longitude) ภายในรัศมีที่กำหนดในระบบ (`jitter_radius_meters`, ค่าเริ่มต้น 20 ม.)
   - เพื่อป้องกันไม่ให้ได้ชื่อสถานที่ว่างเปล่าหรือ "ไม่ระบุสถานที่" ระบบจะวนรอบซ้ำ (สูงสุด `maxAttempts = 3` รอบ) โดยสุ่มพิกัดใหม่และเรียก `resolveLocationWithZoomMeta(jittered.lat, jittered.lng)`
   - หากได้ชื่อสถานที่ที่มีความหมาย (ไม่ว่างเปล่า และไม่มีคำว่า "ไม่ระบุ") ระบบจะยุติการค้นหาทันทีและส่งค่านั้นกลับ
   - หากครบจำนวนรอบแล้วยังไม่ได้ชื่อจากบริการ Geocoding ให้ใช้พิกัดสุ่มรอบสุดท้ายพร้อมชื่อกำกับพิกัด `(พิกัด: lat, lng)` เพื่อความแน่นอนในการบันทึกข้อมูล

## 2. ข้อกำหนดการเลือกพิกัดในคำขอลงเวลากรณีพิเศษ (`#modalSpecialRequest`)
1. **ตัวเลือก 2 รูปแบบ (Radio Toggle):**
   - **ใช้พิกัด GPS ปัจจุบัน (`current`):** ดึงค่าละติจูด/ลองจิจูด และชื่อสถานที่ปัจจุบันที่เบราว์เซอร์ตรวจจับได้อัตโนมัติ
   - **ปักหมุดแผนที่ / ระบุพิกัดเอง (`custom`):** อนุญาตให้ผู้ใช้ค้นหาสถานที่ หรือลากหมุดบนแผนที่ได้เอง
2. **ระบบค้นหาและปักหมุดบนแผนที่ (Interactive Leaflet Map):**
   - ใช้ Leaflet.js v1.9.4 พร้อม OpenStreetMap tiles
   - **การค้นหาสถานที่สไตล์ Google Maps Autocomplete (`#spMapSearchInput` & `#spMapSearchResults`):**
     - รองรับการพิมพ์พิกัดโดยตรง รูปแบบ `lat, lng` (เช่น `13.7563, 100.5018`) และปักหมุดนำทางได้ทันที
     - กลไก Debounce 350ms เมื่อผู้ใช้พิมพ์ตัวอักษรตั้งแต่ 2 ตัวขึ้นไป พร้อมปุ่มค้นหาและรองรับการกด Enter
     - ค้นหาผ่าน OpenStreetMap Nominatim API พร้อมจำกัดเฉพาะในประเทศไทย (`countrycodes=th&accept-language=th&addressdetails=1`) สูงสุด 5 รายการ
     - คำนวณระยะห่างระหว่างตำแหน่งปัจจุบันกับสถานที่ในรายการด้วยสูตร Haversine (`• xx ม.` หรือ `• xx.x กม.`)
     - จำแนกประเภทสถานที่และแสดง Badge อัตโนมัติ (เช่น สถานที่ราชการ กทม., วัด, สถานศึกษา, สวนสาธารณะ, อาคารสำนักงาน ฯลฯ)
     - มีระบบป้องกัน Race Condition ด้วย Search Sequence ID (`searchSeq`)
     - รองรับการปิดกล่องผลลัพธ์เมื่อคลิกภายนอก (Click Outside) หรือกดปุ่ม `Escape`
     - เมื่อผู้ใช้คลิกเลือกสถานที่ จะส่งพิกัดไปยัง `updateCustomPinAndLocation` และสั่ง `map.flyTo` ไปยังตำแหน่งใหม่อย่างนุ่มนวล
   - **การลากหมุด (Draggable Pin) & คลิกบนแผนที่:**
     - หมุดสามารถลากปล่อย (Drag & Drop) ได้อย่างอิสระ คล้ายระบบแชร์ Location ในแอป LINE
     - สามารถคลิกที่จุดใดก็ได้บนแผนที่เพื่อย้ายหมุดไปยังตำแหน่งนั้นทันที
     - ทุกครั้งที่ตำแหน่งหมุดเปลี่ยน ระบบจะเรียก `AttendanceModel.resolveLocationName` เพื่ออัปเดตชื่อสถานที่ให้อัตโนมัติ
   - **การแสดงผลในโมดอล:**
     - ป้องกันปัญหาแผนที่โหลดไม่สมบูรณ์ (Gray tiles) โดยสั่ง `spLeafletMap.invalidateSize()` หลังโมดอลหรือแท็บแสดงผล 250ms
     - ป้องกันปัญหาโมดอลยาวเกินจอด้วยคลาส `max-h-[90vh] overflow-y-auto`
3. **การนำพิกัดไปใช้งาน:**
   - พิกัดที่เลือกในโหมด `custom` จะถูกส่งเป็นพิกัดขาเข้า (`lat`, `lng`, `location_name`)
   - และนำไปเป็นพิกัดตั้งต้นสำหรับระบบสุ่มพิกัดขาออก (`out_lat`, `out_lng`, `checkout_location_name`) ผ่าน `AttendanceModel.resolveJitteredCheckoutWithLocation`
