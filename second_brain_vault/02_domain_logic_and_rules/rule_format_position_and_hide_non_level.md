# Domain Rule: การจัดรูปแบบแสดงผลตำแหน่งและระดับ (BMA Position Formatting Standard)

## 1. บริบทและปัญหาเดิม
ในระบบราชการกรุงเทพมหานคร (กทม.):
- ลูกจ้างชั่วคราว หรือตำแหน่งบางประเภทไม่มีระดับตำแหน่ง ในฐานข้อมูลกำหนดเป็น `"ไม่มี"` การนำมาต่อสตริงเดิม `${position_title}${position_level}` ก่อให้เกิดข้อความไม่พึงประสงค์ เช่น `"พนักงานขับรถยนต์ไม่มี"` หรือ `"พนักงานเทศกิจไม่มี"`
- ตำแหน่งประเภทผู้บริหาร (เช่น ผู้อำนวยการส่วน, หัวหน้ากลุ่มงาน) มีการระบุระดับตำแหน่งในระบบฐานข้อมูลเพื่อการจัดลำดับชั้น แต่ในการแสดงผลคอลัมน์ตำแหน่งหรือหัวฟอร์มโปรไฟล์ ไม่ต้องการให้แสดงผลระดับ (เช่น แสดงเป็น `"ผู้อำนวยการส่วน"` แทนที่จะเป็น `"ผู้อำนวยการส่วนอำนวยการระดับสูง"`)
- ลูกจ้างประจำ หรือระดับกลุ่ม `[ส 1-4, บ 1-4, ตัวเลข]` มีระเบียบการเขียนที่ต้องเว้นวรรค 1 ช่องระหว่างตำแหน่งและระดับ เช่น `"พนักงานเทศกิจ ส 2"` หรือ `"พนักงานขับรถยนต์ 2"`
- ข้าราชการสามัญที่มีระดับปกติ แสดงผลชื่อตำแหน่งติดกับระดับ เช่น `"นักจัดการงานทั่วไปปฏิบัติการ"`

## 2. กฎการแสดงผล 3 รูปแบบ (BMA Standard Rules)

### กฎข้อที่ 1: การซ่อนระดับตำแหน่ง (Omit Level)
1. **ระดับเป็น "ไม่มี":**
   - หาก `position_level` มีค่าเท่ากับ `"ไม่มี"`, `"ระดับไม่มี"`, `"-"`, หรือค่าว่าง ➔ **ไม่แสดงผลระดับ**
   - ตัวอย่าง: `ตำแหน่ง: พนักงานเทศกิจ, ระดับ: ไม่มี` ➔ `"พนักงานเทศกิจ"`
   - ตัวอย่าง: `ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: ไม่มี` ➔ `"พนักงานขับรถยนต์"`
2. **ประเภทตำแหน่งเป็น "ประเภทผู้บริหาร":**
   - หาก `position_type` มีค่าเท่ากับ `"ประเภทผู้บริหาร"` (หรือมีคำว่า `"ผู้บริหาร"`) ➔ **ไม่แสดงผลระดับ**
   - ตัวอย่าง: `ประเภท: ประเภทผู้บริหาร, ตำแหน่ง: ผู้อำนวยการส่วน, ระดับ: อำนวยการระดับสูง` ➔ `"ผู้อำนวยการส่วน"`
   - ตัวอย่าง: `ประเภท: ประเภทผู้บริหาร, ตำแหน่ง: หัวหน้ากลุ่มงาน, ระดับ: ชำนาญการพิเศษ` ➔ `"หัวหน้ากลุ่มงาน"`

### กฎข้อที่ 2: การเว้นวรรค 1 ช่องระหว่าง [ตำแหน่ง] และ [ระดับ] (Needs 1 Space)
- **เงื่อนไข:** ประเภทตำแหน่งเป็น `"ลูกจ้างประจำ"` (หรือมีคำว่า `"ลูกจ้าง"`) **หรือ** ระดับตำแหน่งอยู่ในกลุ่ม `[ส 1-4, บ 1-4, ตัวเลข]`
- **การแสดงผล:** `${title} ${level}` (มีเว้นวรรค 1 ช่องเสมอ)
- ตัวอย่าง:
  - `ประเภท: ลูกจ้างประจำ, ตำแหน่ง: พนักงานเทศกิจ, ระดับ: ส 2` ➔ `"พนักงานเทศกิจ ส 2"`
  - `ประเภท: ลูกจ้างประจำ, ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: 2` ➔ `"พนักงานขับรถยนต์ 2"`
  - `ตำแหน่ง: พนักงานขับรถยนต์, ระดับ: บ 1` ➔ `"พนักงานขับรถยนต์ บ 1"`

### กฎข้อที่ 3: การแสดงผลติดกัน ไม่เว้นวรรค (Civil Servant Levels)
- **เงื่อนไข:** ข้าราชการสามัญมีระดับมาตรฐาน (ปฏิบัติการ, ชำนาญการ, ชำนาญการพิเศษ, เชี่ยวชาญ, ทรงคุณวุฒิ, ปฏิบัติงาน, ชำนาญงาน, อาวุโส, ทักษะพิเศษ)
- **การแสดงผล:** `${title}${level}` (ติดกัน ไม่เว้นวรรค)
- ตัวอย่าง:
  - `ประเภท: ข้าราชการกรุงเทพมหานครสามัญ, ตำแหน่ง: นักจัดการงานทั่วไป, ระดับ: ปฏิบัติการ` ➔ `"นักจัดการงานทั่วไปปฏิบัติการ"`
  - `ประเภท: ข้าราชการกรุงเทพมหานครสามัญ, ตำแหน่ง: เจ้าพนักงานเทศกิจ, ระดับ: ชำนาญการ` ➔ `"เจ้าพนักงานเทศกิจชำนาญการ"`

## 3. สถาปัตยกรรมโค้ดและการนำไปใช้ (Implementation)
- นิยามฟังก์ชันส่วนกลาง `UIHelpers.formatPosition(title, level, positionType, fullFallback)` ใน `assets/js/core/UIHelpers.js`
- นำไปปรับใช้ใน:
  1. `DashboardController.#renderTable` (ตารางหน้าภาพรวม)
  2. `AttendanceModel.#formatReportRow` (ฟิลด์ `position_full` สำหรับหน้ารายงาน, PDF, และ Excel Export)
  3. `ReportsController` (`#buildSingleRowHtml` และ `#openResumeProfileForSpecificRow` สำหรับ `#resumePositionHeadline`)
  4. `ApprovalsController.#buildRequestRowHtml` (ตารางคำขออนุมัติกรณีพิเศษ)
  5. `PersonnelController` (`#buildPersonRowHtml` และ `#openPersonnelResumeModal` สำหรับ `#perResumePositionHeadline`)
  6. `CheckinController.#renderUserAndSettingsInfo` (`#userPositionText` บนหน้าลงเวลา)
