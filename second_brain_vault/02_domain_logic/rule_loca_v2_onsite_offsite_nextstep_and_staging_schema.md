# Domain Rule: ระบบลงเวลา [ในสถานที่/นอกสถานที่], Next-Step 2 ขั้นตอน, ตัวกรองสังกัดหน้าบุคลากร และ Schema `staging` (`Loca-V2`)

## 1. การแยกฐานข้อมูลสำหรับทดสอบด้วย Schema `staging` (แนวทาง A)
- **สคริปต์สร้างและโคลนข้อมูล**: `sql/create_staging_schema.sql` สร้าง Schema `staging` ในโปรเจกต์ Supabase เดิม (`yicatrqogmcncfpqdyra`) และคัดลอกข้อมูลเดิมครบทั้ง 4 ตาราง (`system_settings`, `personnel`, `user_accounts`, `attendance_logs`) จาก `public` มายัง `staging` โดยอัตโนมัติ
- **การกำหนดค่าในโค้ด**:
  - `Config.SUPABASE_SCHEMA = 'staging'` (บน Branch `Loca-V2`)
  - `DatabaseService.js` ส่ง `{ db: { schema: Config.SUPABASE_SCHEMA || 'public' } }` พร้อมระบบ Auto-Fallback ไปยัง `#publicClient` (`schema: 'public'`) หากผู้ใช้ยังไม่ได้เปิด Exposed schema `staging` บน Supabase Dashboard

## 2. ตั้งค่าระบบ > แท็บที่ 6 "สถานที่และรัศมี" (`FLOW_SETTINGS_01`)
- เก็บข้อมูลในฟิลด์ `official_locations` (JSONB Array ของ `{ id, name, latitude, longitude, radius_meters, is_active }`)
- รองรับการเพิ่ม ลบ แก้ไข และจัดเรียงลำดับสถานที่ราชการได้หลายสถานที่ (`[สถานที่ 1, สถานที่ 2, ...]`) พร้อมปุ่มดึงพิกัด GPS ปัจจุบัน

## 3. หน้าระบบลงเวลาปฏิบัติราชการ (`FLOW_CHECKIN_01`, `FLOW_GPS_01`, `FLOW_PHOTO_01`)
- **ตัวเลือกโหมด `[ในสถานที่, นอกสถานที่]`**: ค่าเริ่มต้นเป็น `"ในสถานที่"` (`ONSITE`) เสมอ
- **โหมดในสถานที่ (`ONSITE`)**:
  - คำนวณระยะทางจริง (หน่วยเป็นเมตร) ด้วยสูตร Haversine Formula เทียบกับสถานที่ราชการทุกแห่งที่เปิดใช้งาน (พร้อมชดเชยความคลาดเคลื่อนสัญญาณในอาคารไม่เกิน 25 เมตร)
  - หากอยู่ในรัศมีอย่างน้อย 1 แห่ง สามารถกดไปต่อ / กดปุ่มบันทึกเวลาได้
  - หากอยู่นอกรัศมีของทุกแห่ง จะล็อกปุ่มไม่ให้บันทึก และแสดงข้อความแจ้งเตือน **`"พิกัดตำแหน่งอยู่นอกสถานที่ทำงาน"`**
- **โหมดนอกสถานที่ (`OFFSITE`)**:
  - ปลดล็อกกฎรัศมีสถานที่ราชการ
  - เลือกรูปแบบการปฏิบัติงานจากตัวเลือกหมายเหตุ (`ปฏิบัติงานนอกสถานที่`, `อบรม`, `ประชุม`, `ปฏิบัติงานที่บ้าน (WFH)`, `อื่นๆ` ที่มีฟิลด์กรอกข้อความเอง) และบันทึกลงคอลัมน์ `remark` เพื่อแสดงในช่อง `"หมายเหตุ"` ของหน้ารายงานการลงเวลา (`"ตารางรายงานสถานะ"`)
  - มีตัวเลือกพิกัด GPS 2 รูปแบบ (`1. ใช้พิกัด GPS ปัจจุบัน`, `2. ค้นหาสถานที่ด้วยตัวเอง` ผ่านแผนที่ Leaflet) บันทึกลง `"พิกัด GPS เข้างาน"` และ `"พิกัด GPS ออกงาน"`
- **UI รูปแบบ Next Step 2 ขั้นตอน (Zero-Scroll)**:
  - **ขั้นตอนที่ 1 (หน้าแรก)**: รวม `พิกัดสถานที่` + `ช่วงเวลา (กรณีปฏิบัติงานนอกเวลา)` แสดงปุ่มขอบล่างจอ **"ถัดไป" (สีเหลือง)** (`#btnNextStepCheckin`)
  - **ขั้นตอนที่ 2 (หน้าสุดท้าย)**: `ถ่ายรูปยืนยันตัวตน` แสดงปุ่มขอบล่างจอ **"บันทึกลงเวลาปฏิบัติงาน" (สีเขียว)** (`#btnSubmitCheckinMain`)
- **ลำดับ Popup มาตรฐาน 3 ขั้นตอน**:
  1. Popup สรุปข้อมูลให้ยืนยันอีกครั้ง
  2. Popup แจ้งเตือน `"ระบบกำลังบันทึกข้อมูล"`
  3. Popup แจ้งเตือน `"ลงเวลาปฏิบัติงานเรียบร้อยแล้ว"`

## 4. หน้าจัดการข้อมูลบุคลากร (`FLOW_PERSONNEL_01`)
- เพิ่มแผง `"กรองข้อมูลตามโครงสร้างองค์กร (ขอบเขต สำนักงาน/กอง)"` (`#hierarchicalPersonnelOrgFilterDock`: `1. สำนักงาน/กอง` > `2. ส่วน/ฝ่าย` > `3. กลุ่มงาน`) สำหรับบัญชี `SuperAdmin` และ `Admin` เฉพาะขอบเขตการมองเห็น `สำนักงาน/กอง` (`visibility_level === 'bureau'`)
