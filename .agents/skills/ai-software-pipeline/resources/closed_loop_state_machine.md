# ตารางลำดับการทำงานแบบวงจรปิด (Closed-Loop Workflow State Machine v2.0)

**ข้อกำหนดระดับระบบ (System Constraints):**
- **โมเดลขั้นต่ำบังคับใช้ (Minimum Model):** `Flash 3.8 High` (สำหรับทุก Agent ตั้งแต่ `agent_00` ถึง `agent_08`)
- **นโยบายความสมบูรณ์ของข้อมูล (Completeness Policy):** `NO_PLACEHOLDERS_OR_TRUNCATION` (ห้ามย่อ ห้ามสรุป และห้ามละโค้ดด้วยคอมเมนต์)
- **ลำดับความสำคัญของความรู้ (Knowledge Priority):** `Active Skills (SKILL.md)` -> `Second Brain Notes (ADR & Pitfalls)` -> `Default Model Knowledge`
