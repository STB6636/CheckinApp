# ตารางลำดับการทำงานแบบวงจรปิดสำหรับ VS Code (Closed-Loop Workflow State Machine — Lean 4-Stage Architecture)

**ข้อกำหนดระดับระบบ (System Constraints):**
- **โมเดลขั้นต่ำบังคับใช้ (Minimum Model):** `Flash 3.8 High` สำหรับ Orchestrator และ SubAgents ทั้ง 2 ตัว (`subagent_01_implementer`, `subagent_02_qa_auditor`) — ห้ามใช้ `flash_lite` เด็ดขาด
- **นโยบายการประหยัดโทเคน (Token-Saving Policy):** `MAP_FIRST_SURGICAL_LINE_RANGE_ONLY` (อ่านสารบัญ `.ai_map/` ก่อนเสมอ -> ดึงโค้ดเฉพาะช่วงบรรทัด `L_start - L_end` -> แก้ไขเฉพาะจุด -> ซิงค์ `.ai_map/` ทันที)
- **กฎเหล็กการแก้ไขโค้ด (Strict Surgical Scope):** `STRICT_SURGICAL_SCOPE_ONLY` ("แก้ไขเฉพาะส่วนที่ต้องแก้ไข, ไม่แก้ไขส่วนที่ไม่เกี่ยวข้อง")
- **ความสมบูรณ์ของโค้ด (Completeness Policy):** `NO_PLACEHOLDERS_IN_TARGET_SCOPE` (โค้ดในจุดที่แก้ไขต้องเขียนจริงครบ 100% ห้ามมี `// TODO` หรือ `// ...`)
- **นโยบายความปลอดภัย Git (Git Safety Policy):** ห้ามรัน `git push` ขึ้น GitHub เด็ดขาด เว้นแต่ผู้ใช้มีคำสั่งชัดเจนให้ push
