# ตารางลำดับการทำงานแบบวงจรปิดสำหรับ VS Code (Closed-Loop Workflow State Machine v3.0)

**ข้อกำหนดระดับระบบ (System Constraints):**
- **โมเดลขั้นต่ำบังคับใช้ (Minimum Model):** `Flash 3.8 High` (สำหรับทุก Agent ตั้งแต่ `agent_00` ถึง `agent_09`)
- **นโยบายการประหยัดโทเคนใน VS Code (Token Saving Policy):** `MAP_FIRST_SURGICAL_LINE_RANGE_ONLY` (อ่านสารบัญ `.ai_map/` ก่อนเสมอ -> ดึงโค้ดเฉพาะบรรทัด `L_start - L_end` -> แก้ไขเฉพาะฟังก์ชัน -> ซิงค์เลขบรรทัดกลับเข้าสารบัญทันที)
- **นโยบายความสมบูรณ์ของโค้ด (Completeness Policy):** `NO_PLACEHOLDERS_IN_TARGET_SCOPE` (ภายในฟังก์ชันหรือไฟล์ที่กำลังสร้าง/แก้ไข ต้องเขียนโค้ดจริงครบ 100% ทุกบรรทัด ห้ามละด้วยคอมเมนต์)
